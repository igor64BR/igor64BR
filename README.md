## Selected projects

### [Even / Tô Quite](https://github.com/igor64BR/even)

An expense-splitting app with a native Android client in Kotlin and a .NET backend. It works offline without an account and uses a balance-graph algorithm to simplify group debts. Optional sync uses SignalR; local data stays in Room/SQLite.

### [Express + TypeScript + Prisma](https://github.com/igor64BR/express-ts-prisma-template)

An Express 5 API starter with TypeScript, Prisma 7, PostgreSQL and Inversify. It includes a user/post model, repository interfaces and nested writes. The README documents setup, request flow and the gaps to address before production use.

### [Weather Forecast](https://github.com/igor64BR/react-challenge-01-weather-forecast)

A responsive weather app built with Next.js, React and TypeScript. It supports city search and browser geolocation using OpenMeteo and OpenWeatherMap. I built the UI components without a component library or CSS framework.

[Try the weather app](https://react-challenge-01-weather-forecast.vercel.app/).
